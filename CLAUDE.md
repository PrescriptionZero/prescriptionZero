# prescriptionZero — Monorepo

## Overview

Privacy-preserving digital prescription platform built on Midnight (Zero-Knowledge proofs).

- Patients redeem controlled medications via ZK proofs without exposing identity or diagnosis.

## Tech Stack

- Smart Contracts: Compact (Midnight DSL)
- SDK: Midnight TypeScript SDK (`midnight-js`)
- Frontend: React + TypeScript + Tailwind CSS
- Backend: Node.js + Express + TypeScript + PostgreSQL
- Package Manager: npm
- Agent Integration: Claude Code with `.agents/skills/`

## Project Structure

- `contract/`: Compact circuits, tests, and autogenerated TS bindings (`managed/`).
- `frontend/`: React SPA with 3 main roles (/medico, /paciente, /farmacia).
- `backend/`: Express server for PostgreSQL relational data (medicine catalog, doctor list).

## Common Commands

- Install all dependencies: `pnpm install` (in each directory)
- Build Compact contract: `cd contract && pnpm run build`
- Run contract tests: `cd contract && pnpm test`
- Run backend server: `cd backend && pnpm run dev`
- Run frontend app: `cd frontend && pnpm run dev`
